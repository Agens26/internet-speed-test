# Измерение скорости скачивания

Консольный скрипт выполняет 10 последовательных HTTP- или HTTPS-запросов к указанному адресу. Каждый ответ считывается до конца. Затем скрипт выводит среднее время запроса, общий объём скачанных данных и среднюю скорость в мегабитах в секунду (Мбит/с).

## Запуск

Требуется Python 3.10 или новее. Дополнительные библиотеки не нужны.

```bash
python speed_test.py "https://www.python.org/static/img/python-logo.png"
```

Укажите адрес доступного файла или страницы. Для более показательного измерения подойдёт достаточно большой файл с сервера, который разрешает его скачивание. Скрипт загрузит этот файл 10 раз, поэтому учитывайте объём трафика и ограничения сервера. Вместо `python` в некоторых системах используется `python3` или `py -3`.

## Расчёт

- Среднее время запроса: сумма времени десяти запросов / 10.
- Общий объём: сумма размеров тел десяти ответов в байтах.
- Средняя скорость: общий объём в байтах × 8 / сумма времени запросов / 1 000 000. Результат выражен в Мбит/с; 1 Мбит = 1 000 000 бит.

Время каждого запроса измеряется от отправки запроса до полного считывания ответа, включая ожидание ответа сервера. Поэтому результат показывает скорость загрузки именно с указанного сервера, а не обязательно максимальную пропускную способность интернет-соединения. Заголовки HTTP в объём данных не включаются.

Если запрос завершается ошибкой или превышает тайм-аут, скрипт выводит сообщение и завершает работу с ненулевым кодом. Частичные результаты не выдаются за итог десяти запросов.

## Проверка

Чтобы запустить автоматические тесты, находясь в папке проекта, выполните:

```bash
python -m unittest -v test_speed_test
```

Тесты запускают временный локальный HTTP-сервер. Они проверяют десять запросов и общий объём, обработку ошибки сервера, некорректный адрес и расчёт скорости на известных данных. Для локального сервера система должна разрешать соединения с `127.0.0.1`.
